# 临时图片命名去分镜化

## DO

- 将生图/提示词编辑器中临时粘贴图片的默认展示名从 `分镜图1`、`分镜图2` 改为 `图片1`、`图片2`。
- 覆盖 AI 可见内容：粘贴图片后插入 prompt 的 mention label 必须使用 `图片N`。
- 覆盖用户可见内容：临时图片在 mention 候选项、相关临时图显示中的默认 label 使用 `图片N`。
- 同步更新相关测试，防止临时图默认命名回退为 `分镜图N`。

## DON'T

- 不修改角色库图片、角色素材、音频素材的命名逻辑。
- 不修改后端素材存储、asset id、文件路径、tags 或粘贴导入流程。
- 不修改图片数量限制、mention 数据结构或生图 API 请求格式。
- 不处理非临时图场景中的业务术语，除非它会影响临时粘贴图片的用户/AI 可见命名。

## VERIFY

- 粘贴第一张临时图片后，prompt mention 显示为 `图片1`。
- 粘贴第二张临时图片后，prompt mention 显示为 `图片2`。
- 临时图片 mention 候选项默认 label 为 `图片N`。
- 代码搜索确认用户/AI 可见的临时图片默认命名不再使用 `分镜图N`。
- 相关前端测试通过；必要时运行 `npm test`。
