# v0.2.5

## Merge Summary

本次版本围绕调度器的存储性能、批量操作和产出洞察完成升级：将运行状态从单体 `state.json` 迁移到 SQLite，降低任务增多后的暂停、删除和状态刷新卡顿；补齐批量选择、暂停、排队与删除操作；新增生成统计，可快速切换今天、昨天和最近 7 天，并按标准/Fast 模型筛选和下钻到对应完成任务。

## Changes

- **SQLite 状态存储**: 新增 SQLite 持久化层与旧 `state.json` 自动迁移，桌面端和 MCP 共用同一数据源，保留兼容回退与迁移保护。
- **批量任务管理**: 支持本页批量选择、排队、暂停和删除，减少逐条操作成本；状态操作从界面主流程解耦，改善大任务量下的交互卡顿。
- **生成统计**: 在共享调度池区域增加轻量统计入口，详情弹窗展示产出总量、标准模型和 Fast 模型贡献，以及对应完成任务列表。
- **日期下钻**: 支持今天、昨天、最近 7 天快速切换；最近 7 天柱状图可点击，选中日期后同步更新数量、模型占比和任务列表，并高亮对应柱子。
- **按需访问视频**: 生成结果默认不再自动下载，本地无文件时通过远程链接按需查看，降低磁盘、网络和界面资源占用。
- **任务详情优化**: 命中资源与命令参数默认展开，保留高级双车道和共享调度策略；完成记录可回到对应任务详情。
- **布局修复**: 修正统计弹窗顶部概览区溢出、列表行列错位和滚动区域挤压问题，统一不同窗口尺寸下的弹性布局。
- **原型同步**: 更新调度池统计交互原型，保持设计稿与实际实现一致。
