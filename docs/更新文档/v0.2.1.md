# v0.2.1

## Merge Summary

本次版本将结构化日志中心、生图与素材引用体验、应用图标更新、运行时白屏修复和 CI 打包修复归档为稳定发布，重点提升调度器的可观测性、安装包一致性和日常操作反馈。

## Changes

- **日志中心**: 后端日志升级为结构化 `LogEntry`，兼容旧字符串日志；前端新增日志中心统计、分类、表格、详情、筛选、复制、导出、定位任务和分页能力。
- **前端交互**: 准备生成、立即生成、查询结果等关键按钮增加 loading/disabled 反馈，避免长操作期间看起来卡死。
- **白屏修复**: 修复 `Dashboard -> TaskDetail` 的 `pendingTaskOps` 传参缺失导致生产包启动白屏的问题，并保留应用级 ErrorBoundary 以便后续显示启动错误。
- **生图体验**: 增强图片上下文菜单控制，补充相关工具函数与测试。
- **应用图标**: 使用新的即梦调度器图标替换 macOS/Windows 多尺寸资源，补齐 `.icns` 大尺寸图标以修复 DMG 安装窗口图标空白。
- **CI 打包**: GitHub Actions Windows 构建改为只生成 NSIS 包，绕过 WiX/MSI `light.exe` 失败。
- **测试补充**: 新增日志视图、图片上下文、设置页 UI 等单测，更新 Rust 结构化日志相关测试。
