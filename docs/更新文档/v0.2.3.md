# v0.2.3

## Merge Summary

本次版本补齐 `图片N` 临时图片 mention 的前后端链路，确保粘贴/临时参考图在编辑器、草稿、队列资源展示和命令参数解析中保持一致，并继续兼容旧的 `分镜图N` 表达。

## Changes

- **临时图 mention 持久化**: 将 `tempImageAssetIds` 写回任务表单的 `temp_image_asset_ids`，避免编辑器已匹配但草稿或队列资源丢失临时图语义。
- **创建表单同步**: 统一使用 `applyMentionRefsToTaskForm` 合并 prompt mention 引用，并补齐 `temp_image_asset_ids` 变化比较。
- **队列资源展示**: 按素材自身的临时标签识别临时参考图，兼容缺少 `temp_image_asset_ids` 的旧任务数据。
- **命令参数解析**: 后端支持按序号解析 `@图片N`，并保留 `@分镜图N` 兼容，确保临时参考图进入 `--image` 参数。
- **回归测试**: 增加前端 mention 持久化、队列资源分类和后端 `@图片N` 命令解析测试。
