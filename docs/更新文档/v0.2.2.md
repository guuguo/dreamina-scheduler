# v0.2.2

## Merge Summary

本次版本修复图片生成模型配置持久化、历史操作命令缺失和图片生成接口异常诊断问题，同时优化临时/粘贴图片命名，避免 `分镜图N` 误导 AI 对参考图语义的理解。

## Changes

- **生图模型配置**: 增强图片模型配置归一化、保存日志和前端设置草稿保护，确保新增图片模型与当前激活模型稳定保存并被生成流程使用。
- **生图历史操作**: 补齐并注册重新生成、重新查询、下载图片等 Tauri 命令，增加前后端命令契约测试。
- **接口错误诊断**: 图片生成提交和查询响应统一走 JSON 解析辅助函数，遇到 HTML 页面时返回可读的 Base URL / 路径前缀诊断信息。
- **临时图片命名**: 将粘贴/临时图片默认命名从 `分镜图N` 改为 `图片N`，并兼容旧草稿中的 `分镜图N` mention 推断。
- **任务与素材引用**: 完善任务复制、编辑、素材 mention、临时图恢复和 prompt 解析相关测试，降低引用丢失和误绑定风险。
- **调试脚本**: 增加任务提交回放、失败任务检查和 submit_id 注入脚本，便于本地排查任务链路问题。
