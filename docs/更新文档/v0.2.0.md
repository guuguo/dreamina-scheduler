# v0.2.0

## Merge Summary

本次版本提升聚焦于扩展即梦调度器的图片生成能力、素材引用链路、设置页配置体验和日志中心结构化重构，为后续多模态工作流和可观测性打基础。

## Changes

- **生图模块**: 新增独立的生图 Tab、图片生成表单、参考图管理、预览状态和历史记录能力。
- **素材引用**: 增强 Prompt mention 解析与绑定逻辑，支持图片、临时图和素材引用在任务与生图流程中复用。
- **后端能力**: 扩展 Tauri/Rust 侧图片生成、素材处理、Base64/PNG/HTTP 请求等支撑能力。
- **设置页重构**: 增加 AI 模型多配置、图片生成模型配置、CLI 状态组件和编号卡片布局。
- **UI 统一**: 调整设置页卡片标题字体大小和字重，与全局 12px 字体体系保持一致。
- **测试补充**: 增加 prompt mention 与素材绑定相关测试覆盖。
- **日志中心重构**: 后端日志从 `Vec<String>` 升级为结构化 `Vec<LogEntry>`，支持级别/来源/分类/任务关联等字段；新增 `append_log`/`append_task_log` 统一写入 helper，覆盖素材、角色、任务、队列、CLI、AI 模型测试、生图等全部日志路径；前端新增日志中心四区布局（统计卡片、左侧分类、中间表格、右侧详情面板），支持搜索、级别/来源/任务/时间筛选、导出 JSON/文本、复制日志、定位任务、查看上下文、自动刷新开关和分页；旧字符串日志通过 serde 自定义反序列化器兼容读取；新增 `log-view-utils.js` 派生工具与 37 项单测；新增 StatCard/SearchBox/FilterSelect/InlineCopyButton/Pager 五个 UI 基建组件。
